# Forged metal frame

Original AI-generated material created for Rune Fellowship on 10 September 2026, using the approved Rune app concept as a style reference. No third-party game textures were used for this asset.

`forged-metal.png` is a text-free charcoal iron texture with muted bronze wear, retained from the first frame experiment. It is no longer referenced by the launcher: user feedback favoured quiet satin gradients and no corner ornaments. Current frame and footer button surfaces are drawn by WPF.

The rune core and halo animate only their cached opacity, resting dimly between flares. Windows reduced-motion preferences and minimization stop the animation. Footer buttons are 34 device-independent pixels high and centred in the 58-pixel footer.
