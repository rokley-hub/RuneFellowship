# Rune direwolf assets

The custom saddled direwolf was generated using Meshy and adapted for Rune with corrected face winding, materials, torso shape, skin weights and saddle attachment. `direwolf.skin` contains the generated mesh, UVs, bone bindings and skin weights consumed by `src/Direwolf/DirewolfSkin.cs`. `direwolf-albedo.png` is its texture; `direwolf-mount-icon.png` is a rendered head icon. These three assets are required when building the main game plugin.

The runtime uses the wolf skeleton and animation controller from the player's licensed Valheim installation. No Valheim model, texture, audio or animation clips are included in this asset folder. The desktop direwolf portrait is separate generated illustrative artwork.
