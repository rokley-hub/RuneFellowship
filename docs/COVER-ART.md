# Rune Fellowship artwork

The main page image, `images/rune-fellowship-cover.png`, is the original wide Rune Fellowship promotional banner. It is AI-generated unofficial artwork, not a gameplay screenshot.

The new Thunderstore package icon was generated with OpenAI image generation on 11 September 2026: a red-haired Viking woman, red-bearded dwarf and silver-grey direwolf. The package uses a 256-pixel square resize. This new artwork is for the package icon only; the main promotional banner remains the original image. The separate Rune lettermark and installer artwork are unchanged.
