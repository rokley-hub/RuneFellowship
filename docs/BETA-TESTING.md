# Beta feedback

Use a new test world and character. Record the Rune desktop/gameplay versions, Windows version, CPU, GPU/VRAM, RAM, selected voice engine and AI mode, and relevant installed mod versions. Do not send passwords, login files or full save folders.

For each failure, report:
- What you asked Rune to do (include the recognized text if different).
- What you expected and what actually happened.
- The time and whether it repeats.
- What GOAL / NOW / BLOCKED showed, and whether a written reply or speech arrived.
- The smallest reviewed log excerpt that explains the problem.

Test installation and first start, microphone/voice selection, mute and silent replies, typed conversation, follow interruption, loose wood/stone pickup, full inventory, missing tools/materials, crafting and retained equipment, repair, blueprint completion, combat disengagement, save/reload, profile XML export/import, mod install/disable/update, core update and rollback.

Distinguish confirmed bugs from unsupported actions and improvement ideas. Build success is not proof of gameplay. Report time from end of speech to recognition, accepted action and first audible reply separately where possible.

Start with a small group of 5–10 testers. Stop rollout for data loss, repeated install failures, actions contrary to explicit stop/follow, or leaked private data. Expand only after reviewing those reports.
